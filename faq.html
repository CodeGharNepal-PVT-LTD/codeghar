Help Center & FAQ

Find answers to common questions about our services, process, and technology.

Business & Process

What is your typical project timeline? / सामान्य परियोजना समयरेखा के हो?

A simple MVP usually takes 6–10 weeks. Bigger projects — full web apps, integrations with old systems — can run 3 to 6 months. We give you a realistic timeline upfront, not an optimistic one we will miss.

Do you offer post-launch support? / सुरु गरेपछि सहयोग पाइन्छ?

Yes. Every project includes 30 days of free support after launch — bug fixes, small tweaks, questions. After that, we offer monthly maintenance if you want someone keeping an eye on things.

Where is your team located? / तपाईंको टोली कहाँ छ?

We're based in Bhaktapur, Nepal. Most of our team works from the office, but we collaborate with clients remotely too — calls, shared docs, regular check-ins. Distance hasn't been a problem for the projects we've done outside the valley.

Technical FAQ

What technologies do you specialize in? / कुन प्रविधिमा विशेषज्ञ हुनुहुन्छ?

Mostly React and Next.js on the frontend, Node.js on the backend. For Python work we use FastAPI or Django. Everything runs on AWS or Azure — we pick based on what your project needs and what you're already using.

Can you integrate with my existing systems? / के तपाईं मेरो अवस्थित प्रणालीसँग जोड्न सक्नुहुन्छ?

Usually, yes. We've connected new apps to older systems — SAP, Oracle, custom ERPs, spreadsheets that somehow still run the business. We build APIs or middleware so things talk to each other without breaking what's already working.

How do you handle data security? / डेटा सुरक्षा कसरी गर्नुहुन्छ?

We take security seriously from the start — encrypted data, secure login, regular dependency updates, and code reviews before anything goes live. For projects that need formal compliance, we can work toward those requirements together.
